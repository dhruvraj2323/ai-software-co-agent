# Security Policy

Security is a foundational requirement of the AI Software Co-Agent.

## Reporting Security Issues

Do not disclose security vulnerabilities publicly.

Report security issues through the project's designated private security reporting process.

## Security Principles

- Least privilege
- Explicit authorization
- Policy enforcement
- Workspace isolation
- Secret protection
- Auditability
- Safe failure

Security controls must not be bypassed by agent behaviour or configuration.

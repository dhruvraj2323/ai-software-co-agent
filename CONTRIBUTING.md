# Contributing

## Development Principles

All implementation work must follow the locked project documentation baseline.

Every implementation task must map to its Task ID.

Changes should include appropriate tests and evidence.

## Workflow

1. Identify the Task ID.
2. Review the applicable locked specifications.
3. Implement the smallest required change.
4. Add or update tests.
5. Run the required validation checks.
6. Record evidence.
7. Review the change before completion.

Do not silently change locked architecture or specifications.
